# Security

The Consultant Times is a static site: no server, no database, no user accounts, and no secrets in this repository.

- Report a problem privately through GitHub: Security tab > Report a vulnerability.
- Never commit passwords, tokens or API keys. If one is committed by mistake, rotate it immediately, then remove it.
- Reader submissions (Google Form) are never published verbatim or rendered as HTML.
- The scheduled editor has push access to this repository only. Review its commits under the "Edition" and "Update" messages.
